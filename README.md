# Учебная платформа

Сайт с каталогом лекторов. В каталоге можно искать по фамилии и темам, сортировать лекторов по цене и стажу, смотреть программы и тарифы.

## Стек

- React и React DOM 19.3.0
- Vite 8.3.1 и плагин React 6.1.1
- JavaScript, JSX и CSS
- Node.js 20.19+ в ветке 20.x или 22.12 и новее. Проверено на Node.js 24.21.0 и npm 11.19.0.

## Запуск

```bash
npm ci
npm run dev
```

Откройте `http://localhost:5173`. Для сборки выполните `npm run build`. Результат будет в папке `dist/`.

## Структура проекта

| Путь | Что внутри |
| --- | --- |
| `src/pages/` | Страницы сайта |
| `src/components/` | Компоненты и их стили |
| `src/data/` | Данные лекторов, партнёров, меню и тексты |
| `src/routes.js`, `src/router/` | Таблица маршрутов и код маршрутизации |
| `src/utils/` | Поиск, сортировка и форматирование |
| `src/styles/` | Общие стили и переменные |
| `src/config.js` | Адрес хранилища изображений |

Данные лекторов находятся в [`src/data/lecturers.js`](src/data/lecturers.js).

Изображения загружаются из Yandex Object Storage. Для запуска достаточно подключения к интернету, файл `.env` создавать не нужно. Форма записи работает в демонстрационном режиме.

## Роутинг

Адрес страницы хранится после `#`. Браузер переключает страницы внутри приложения, поэтому прямые ссылки работают и на статическом хостинге без настройки переадресаций.

| Адрес | Страница |
| --- | --- |
| `#/` | Главная |
| `#/partners` | Партнёры |
| `#/about` | О нас |
| `#/lecturers` | Каталог лекторов |
| `#/lecturers/:id` | Профиль лектора |

Маршруты объявлены в [`src/routes.js`](src/routes.js). Код в [`src/router/router.js`](src/router/router.js) читает адрес, обрабатывает его изменение и передаёт найденные параметры в страницу через `App.jsx`. Для внутренних ссылок используется [`Link`](src/router/Link.jsx), который добавляет `#` к адресу и отмечает активный пункт меню.

В адресе `#/lecturers/petrov` значение `petrov` попадает в параметр `id`, по которому профиль находит лектора в данных. Ссылка `#/lecturers?q=Python` открывает каталог с уже заполненным поиском. Если адрес или ID лектора неизвестен, показывается страница 404.

Чтобы добавить страницу, создайте компонент в `src/pages/`, зарегистрируйте путь в `src/routes.js` и используйте `Link` для перехода на него. Если страница нужна в главном меню, добавьте пункт в `src/data/navigation.js`.
